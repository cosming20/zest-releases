# Zest

A file converter that lives in your menu bar (macOS) or notification area (Windows).
Drag a file, hold a key, drop it on a format.

Downloads and a description: https://cosmingagea.com/zest/

Installers are attached to each [release](https://github.com/cosming20/zest-releases/releases).
This repository holds only the release files, the license and the third-party notices.

- macOS 13 or later, Apple Silicon: `Zest-<version>.dmg`
- Windows 10 or 11, x64: `Zest-<version>-Setup.exe`

Zest is MIT-licensed (see `LICENSE`). The conversion engines it bundles keep their own
licenses; see `THIRD-PARTY.txt`. Source archives for the GPL and AGPL engines are attached
to every release.
